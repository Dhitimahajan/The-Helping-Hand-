# 🐾 PawRescue

**An AI-powered animal rescue coordination platform that connects citizens, NGOs, veterinarians, and volunteers to save injured animals faster.**

## The Problem

Every day, injured stray animals are left without timely medical help because people often:

* Don't know the nearest animal NGO
* Can't find emergency veterinary hospitals
* Don't know the correct first-aid steps
* Have no single platform for animal rescue

**PawRescue** aims to solve this by making rescue accessible in one tap.

---

## Key Features

### 🚨 Emergency Rescue

* Report an injured animal
* Upload photo or video
* Automatic GPS location
* Notify nearby NGOs instantly

### 🏥 Nearby Help

* Find the nearest NGOs
* Locate veterinary hospitals
* 24×7 emergency helpline numbers
* One-tap calling and directions

### 🤖 AI Assistant

* First-aid guidance
* Injury analysis from uploaded images
* Dog breed identification
* Emergency care recommendations

### ❤️ Community Features

* Lost & Found pets
* Adoption portal
* Volunteer rescue network
* Rescue status tracking
* Donation support for NGOs

---

## How It Works

1. User finds an injured animal.
2. Opens PawRescue.
3. Uploads a photo and description.
4. GPS captures the location automatically.
5. Nearby NGOs receive a notification.
6. An NGO accepts the rescue request.
7. The animal is transported to a veterinary hospital.
8. The user receives live rescue updates.
